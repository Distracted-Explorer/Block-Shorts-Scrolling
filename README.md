# Block_Short_Scrolling

Controls Short on Youtube Converts link of YouTube Shorts From "https://www.youtube.com/"shorts/riotlauZN-0" to "watch?v=riotlauZN-0" which makes it a normal video and not short which is scrollable. You can not deactivate it(I wanted it specifically not the ability to deactivate)

## Installation

- Get the code folder and store it in safe space
- Extract it
- Open extension in browser
- Switch Developer Mode On
- Load Unpacked
- Open the extension Folder
